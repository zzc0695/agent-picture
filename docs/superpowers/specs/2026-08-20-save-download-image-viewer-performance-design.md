# 保存、高清下载、图片放大与交互流畅性设计

## 背景

当前工作台已经可以上传三张参考图、进行 AI 识别、生成效果图，并向后端创建客户方案。但实际交互存在三个问题：

1. 效果页的下载图标没有绑定行为，无法保存高清图片。
2. 客户方案创建成功后没有明确成功反馈和去向，用户无法确认保存结果。
3. 效果图没有细节放大入口，页面切换动画和异步按钮反馈偏慢。

生产日志证明最近一次 `/api/plans` 请求返回 `201`，因此方案保存的主要问题在前端反馈和后续入口；图片下载则是缺少实现。

## 目标

- 让“保存方案”产生可见、可追踪的成功结果。
- 让“下载高清图”真实保存生成图片，而不是无响应图标。
- 为效果图提供始终可见的全屏放大入口。
- 缩短交互动画并为所有长耗时动作提供即时反馈。
- 保持现有 AI 识别、生图、文案和数据库结构不变。

## 交互设计

### 保存方案

- 效果页主按钮文字改为“保存方案”。
- 点击后立即进入保存中状态并阻止重复提交。
- 后端返回创建的方案 ID 后，界面显示“方案已保存”成功提示。
- 成功提示提供“查看客户方案”入口，跳转到 `/plans`。
- 保存完成后仍允许进入当前方案展示页，不强制离开当前上下文。
- 保存失败时在当前页面显示可读错误，并恢复按钮。

### 下载高清图

- 下载按钮显示“下载高清图”文字，避免仅靠图标表达功能。
- 点击后立即显示“下载中”状态。
- 通过同源下载接口读取已生成图片并返回 `Content-Disposition: attachment`。
- 下载接口只允许已知的应用上传路径和 Vercel Blob 图片地址，避免成为任意 URL 代理。
- 文件名使用包含时间戳的可识别名称，例如 `curtain-plan-20260820.png`。
- 下载失败时显示错误，并保留在当前效果页。

### 图片放大

- 采用已确认的 A 方案：效果图右上角放置固定的放大图标按钮。
- 点击后打开覆盖当前工作台的全屏图片查看器。
- 查看器支持放大、缩小、复位、滚轮缩放、触控双指缩放和拖动查看。
- 支持点击关闭键、点击遮罩和按 Escape 关闭。
- 查看器内保留“下载高清图”入口。
- 弹窗打开时锁定背景滚动，并提供正确的对话框语义和无障碍标签。

## 性能与反馈

- 页面换步动画从 500–800ms 降到约 180–220ms。
- 去除页面切换中的 CSS `filter: blur(...)` 动画，降低合成开销。
- 不使用一个全局忙碌状态锁住无关按钮；上传、识别、生图、保存和下载分别显示自己的进行中状态。
- 所有异步按钮点击后在同一帧更新文字或加载图标。
- 对会发起网络请求的按钮阻止重复点击。
- 图片查看器仅在打开时渲染，避免增加常态页面开销。

## 数据流

### 方案保存

1. 前端整理当前房间图、两张材质图、识别结果、提示词、效果图和营销文案。
2. 前端调用 `POST /api/plans`。
3. API 创建 `CustomerPlan` 并返回完整方案和 ID。
4. 前端保存方案 ID，展示成功提示和 `/plans` 导航入口。

### 高清下载

1. 前端把当前效果图 URL 传给同源下载接口。
2. 接口验证登录状态和图片 URL 来源。
3. 接口读取图片并以附件响应返回，同时保留正确的图片 MIME 类型。
4. 浏览器触发本地文件保存。

## 组件边界

- `WorkbenchPage`：维护工作流、保存状态、下载状态和成功/错误反馈。
- `ResultView`：展示效果结果和明确的保存、下载、放大操作。
- `ImageViewer`：独立负责全屏图片查看和缩放交互，不负责业务保存。
- 下载 API：独立负责图片来源验证、读取和附件响应。

## 错误处理

- `postJson` 读取 API 返回的错误字段，优先展示后端可读错误，不再只显示请求路径。
- 保存、下载、生图和文案生成都使用 `catch` 更新页面错误状态。
- 图片下载遇到上游失败、非图片响应或不允许的主机时返回明确的 4xx/5xx JSON 错误。
- 无有效生成图时禁用下载和放大按钮。

## 验证标准

- 单元/组件测试覆盖保存成功、保存失败、下载触发、放大查看器打开与关闭。
- 下载接口测试覆盖授权、允许来源、拒绝任意外部 URL和附件响应头。
- `npm test`、lint、TypeScript 和生产构建全部通过。
- 浏览器验证按钮按下即时反馈、方案成功提示可见、放大查看器可操作。
- 部署后检查 `/api/plans` 与下载接口的生产日志，没有 4xx/5xx 或未处理异常。

## 非目标

- 本轮不改数据库模型。
- 本轮不增加方案编辑、删除或分享权限。
- 本轮不改 AI 模型、提示词结构或图片生成参数。
