# AI 软装 MVP

## 商家使用

1. 用邮箱、至少 8 位密码和店铺名称注册；首次进入阅读使用指南。
2. 在「客户」登记称呼、联系方式与备注；工作台也允许仅填写称呼。
3. 工作台选择客户，上传房间、整体款式、材质细节三张图片（JPG、PNG、WebP，每张不超过 4 MB）。可先识别图片，再调整生成要求与还原度。
4. 提交生图后可关闭页面；再次进入工作台会恢复正在生成的任务。失败会显示原因，可重试。
5. 生成营销文案，保存方案。在「方案」按客户、状态、关键词筛选，并修改客户、备注、文案与状态。
6. 创建客户交付链接，复制后自行发送。客户无需账号即可查看原图、效果图与客户方案说明，下载图片、打印或保存 PDF。链接有效 7 天，可撤销；再次创建失效链接会使用新地址。方案修改会同步到当前交付页。

客户删除后已有方案保留；方案删除会使分享失效。客户交付页不显示联系方式、内部备注、生成提示词或营销脚本。交付链接允许持有该链接的人访问，请仅发送给对应客户。

## 可配置用量

在 Vercel 项目环境变量中修改并重新部署：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| AI_DAILY_IMAGE_LIMIT | 10 | 每个商家每日生图请求数 |
| AI_DAILY_TEXT_LIMIT | 30 | 图片识别、要求润色、营销文案合计每日请求数 |
| AI_MAX_CONCURRENT_IMAGES | 1 | 每个商家同时进行的生图任务数 |
| AI_IMAGE_ESTIMATED_PRICE | 0 | 每次生图请求预估人民币成本 |
| AI_TEXT_ESTIMATED_PRICE | 0 | 每次识别或文案请求预估人民币成本 |

次数上限设为 0 表示不限。每日按北京时间零点重置，已发起的失败请求也计次数。费用是按配置单价和请求数估算，不是供应商账单，也不会向用户扣费。默认单价 0 表示尚未配置费用估算；真实计费查看阿里云控制台。额度检查和请求预留在数据库事务中执行，超额请求在模型调用前返回 429。

## 部署

GitHub main 分支由 Vercel 自动发布。构建执行 `prisma migrate deploy`、生成客户端与 Next.js 构建；数据库迁移增加客户、引导状态、分享和费用字段，不清空已有数据。

需配置 DATABASE_URL、SESSION_SECRET、DASHSCOPE_API_KEY、BLOB_READ_WRITE_TOKEN。模型和地区通过 DASHSCOPE_TEXT_MODEL、DASHSCOPE_IMAGE_MODEL、DASHSCOPE_BASE_URL 设置。预览环境与生产环境若使用同一数据库，测试账号和记录也会出现在同一数据库中。

MVP 暂不包括找回密码、邮箱验证、支付、团队权限与独立后台。先由实际商家试用验证流程，再决定扩展。
